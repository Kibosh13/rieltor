# Бюро недвижимости Марины Сырник

Адаптивный сайт эксперта по недвижимости, созданный по ТЗ и материалам заказчика.

- Демонстрация: https://kibosh13.github.io/rieltor/
- Репозиторий: https://github.com/Kibosh13/rieltor
- Основная ветка: `main`.
- Публикация GitHub Pages: ветка `gh-pages`, каталог `/`.

## Структура

```text
site/
  index.html       Страница со всеми разделами и текстами
  styles.css       Оформление и адаптивные стили
  app.js           Мобильная навигация
  assets/          Фотографии, логотип и локальные шрифты
  .nojekyll        Публикация обычных статических файлов без Jekyll
```

`site/` содержит исходные HTML, CSS, JavaScript и изображения. Проект не требует сборки, npm, сервера приложений, базы данных или внешних запросов к сервисам шрифтов. Каталог `dist/` и другие генерируемые результаты исключены через `.gitignore`.

## Локальный просмотр

Откройте `site/index.html` в браузере или выполните:

```bash
python3 -m http.server 4173 --directory site
```

После этого сайт доступен по адресу http://localhost:4173/.

## Обновление

Редактируйте файлы в `site/` в ветке `main`. Проверьте изменения перед отправкой:

```bash
git diff
git status --short
git add site README.md .gitignore
git commit -m "Update website content"
git push origin main
git subtree push --prefix=site origin gh-pages
```

Git отправляет изменения файлов. Архивы, локальные зависимости и результаты сборки не нужны. История `gh-pages` сохраняется; `--force` не применяется. GitHub Pages автоматически публикует изменения из `gh-pages`.

## Индексация демонстрации

В HTML заданы `robots` и `googlebot` со значениями `noindex, nofollow, noarchive, noimageindex`. Эти правила запрещают индексацию демонстрационной страницы поисковыми системами, которые их поддерживают. Демо остаётся доступным по прямой ссылке.

`Disallow: /` не используется: поисковые системы должны загрузить HTML, чтобы увидеть `noindex`. Файл `robots.txt` в каталоге `/rieltor/` не управлял бы обходом домена: поисковики читают его только из корня `https://kibosh13.github.io/robots.txt`.

В опубликованном корневом `robots.txt` репозитория `Kibosh13/Kibosh13.github.io` (ветка `gh-pages`) добавлены только исключения `Allow: /rieltor/$` и `Allow: /rieltor/*.html$`. Они позволяют прочитать `noindex`; существующий запрет обхода изображений и правила остальных проектов сохранены. При обновлении корневого сайта сохраняйте эти исключения.

При переносе на основной домен заказчика отдельно согласуйте снятие `noindex`.

## Возможности

Сохранены все направления ТЗ: продажа, покупка новостроек и вторичного жилья, земельные участки и дома, ипотечный брокеридж и страхование, аренда и найм, хоумстейджинг. Работают якорная навигация, мобильное меню, звонок по телефону и переход в WhatsApp. Все описания услуг показаны целиком.

Отключённых функций в статической демонстрации нет: она соответствует полному сайту. Форма отправки заявок, личный кабинет, CRM, база объектов и серверная часть в исходном проекте отсутствуют.

## Материалы и безопасность

В репозитории только необходимые материалы сайта. Исходные письма и ТЗ, токены, пароли, базы данных, `.env`, служебные настройки хостинга, логи и архивы не публикуются. Изображения оптимизированы в WebP; внешность на фотографиях не изменялась. Главный портрет выбран согласно указанию заказчицы.

Фотографии, логотип и тексты предоставлены заказчиком; размещение в открытом репозитории само по себе не предоставляет лицензию на их повторное использование.

## Оформление по референсам заказчицы

Сохранена шапка с логотипом. Сразу после неё размещены главная фотография, цитата курсивом, рукописная подпись и приветствие. Тексты услуг выровнены по центру, подзаголовки выделены жирным; скрытых описаний и кнопок «Подробнее» нет.

Шрифты Open Sans и Great Vibes включены локально в WOFF2 с поддержкой кириллицы и латиницы. Лицензии SIL Open Font License находятся рядом с файлами шрифтов в `site/assets/fonts/`. Реквизиты и текст информационного уведомления перенесены из предоставленного заказчицей референса.
